## 3. Source vs Riva MT vs Qwen Review Attribution (`D5`, `D6`)
- Across `234` utterances: **`75` (`32.1%`)** were modified by Qwen review (`39` API calls, `0` errors); **`19`** of the `90` micro-utterances changed under review.
- Independent comparison of `source_text` -> `machine_translated_text` (Riva) -> `translated_text` (Qwen) separates four distinct mechanisms:
  1. **Upstream ASR corruption (`A`, propagated unchanged through E/F):** e.g. *Enfant -> Au chant*, *Condor -> convoi*, *Laguerra -> la girafe*, *Rana Ori -> Rana-Ari / Oranaori*, *naacal -> Nakal / Natal / Akâln*, *Ambrosius -> ambroisie / Andréus / Mon gros Zeus*, *il pleut des rats -> il pleuvra*, *alors qu'il a -> Alice a*. Neither Riva nor Qwen had domain glossary conditioning (`glossary=null`).
  2. **Legitimate Qwen repairs of Riva errors:** e.g. `utt-0011` (`"I could feel..."` -> `"They felt..."`), `utt-0021` (restored missing opening clause `"My sleep grenades."`), `utt-0169` (`"This ambrosia,"` -> `"This Ambrosius, he"`), `utt-0171` (`"ambrocious"` -> `"Ambrosius"`), `utt-0215` (`"Our churches"` -> `"The eleven churches"`), `utt-0232` (`"path"` -> `"game"`).
  3. **Context-starved fragment guesses / regressions (`B/D -> F`):** When CTC/flicker isolated `"larguée, commandant!"` (`S01`, `utt-0018`) without `"Parée en"`, Riva inferred context (`"Good work, Commander!"`) whereas Qwen literally overwrote it to `"Dropped, Commander!"`; isolated `"Mes"` (`W04c`, `utt-0207`) became Riva `"We"` -> Qwen `"My"`; distorted `"Boulot!"` (`utt-0025`) became Riva `"get to work!"` -> Qwen proper noun `"Now, Boulot!"`.
  4. **Rare pure Qwen semantic regression on coherent source (`F`):** `S02` (`utt-0070`) preserved French negation cleanly in Riva (`"It wasn't our Nakal who thought of that!"`), but Qwen review dropped the negation (`"Our Nakal would have thought of that!"`), inverting speaker intent. `W04b` (`utt-0206`) truncated trailing `"On"` was turned by Riva into fluent `"We did it, Tao! We did it!"` then chopped back by Qwen to `"We did it, Tao! We"`.
