# Recording context and evidence-directed nominations

Current source quality authenticates the original recording and its ledger
before projecting compact original source rows with bound unit references.
One native NInfer Messages text phase runs recording context. Structural boundary cases enter the shared acoustic scheduler directly, without redundant per-case text votes. The source is unchanged. Explicit xhigh effort, 2048
thinking tokens and 8192 completion tokens leave separate answer capacity.
Native usage reports input, output and thinking tokens; no character/token
estimate is reported as tokenizer evidence. A byte envelope admits a request
or partitions it at source row boundaries. Explicit native length/context
exhaustion also subdivides; incomplete answers never produce proposals.
Each recording is bounded by eight native calls, with uncovered or rejected
work explicitly reported. Segmented responses do not claim global cross-segment
relationship coverage. A transport/schema/usage failure is a partial report,
not a reason to invent or silently relax native reasoning settings.

Literal citations must resolve within the actual request and quote unique
observed substrings, with original source row references and their complete unit inventory (not a claim of exact quote-to-unit alignment). Entity and
relationship proposals are advisory only, including suggested spellings; no
automatic glossary, speaker attribution, transcript edit or time assignment.
Consequential anomaly nominations carry one cited original target. The shared
acoustic scheduler receives only its actual provisional event bounds, or an
explicit unlocalized request. Its existing priorities, coalescing, resource
budgets and positive-evidence resolver remain authoritative. Context nominations also enter bounded post-acoustic scene adjudication. See SEMANTIC_ADJUDICATION.md for the grounded context and translation integration. Final geometry promotion remains separate.

The actual current-media CLI and Studio source-quality path invokes the stage.
The acoustic-only evaluation entry remains explicit and does not call context.
Offline rerender remains inference-free.

## Bounded host qualification

Use the current candidate source and existing owned resources. The script
requires current manifest-bound original recording contracts and their sidecars.
It never rewrites an old manifest to accept an incompatible historical input.

Run `PYTHONPATH=src <core-python> -m scripts.evaluate_recording_context --help`.
Use repeated `--recording` with actual authenticated retained bounded French
and multilingual recordings, an absolute `--model-resources` path, optional
`--lifecycle-config`, and a new `--output-dir`. The default mode executes
real native context and the actual planner with/without nominations on the
same inputs, no acoustic/model translation calls. Preserve private response
texts and usage receipts. Review actual hypotheses for unsupported entity
merges, polarity or instruction confusion; abstention is legitimate, not
a failure solely for producing no proposals. Native usage and genuine
coverage must be demonstrated. Test deterministic positive/negative controls
and bounded subdivision via the CPU suite.

If a suitable exact bounded crop is available and actual nominations merit
acoustic investigation, use the same module with one recording and
`--live-media` pointing to its fingerprint-identical media. This uses the
actual source-quality orchestrator, not an alternate resolver. Its bounded
evaluation policy does not change normal defaults. No requirement to repeat
all prior acoustic controls or run a full episode at this increment.

The private source-quality report retains raw answer text; the canonical contract carries only validated hypotheses and compact attempt receipts. No raw rejected answer is passed to downstream consumers.

For planning-only qualification, `--sealed-recovery-archive` accepts the exact previously adjudicated #18 private archive `occurrence-recovery-review-029f969.tar.gz` (SHA-256 `4d46e32e6f2459cb348389aa4362b6a3fdfd2dddba56391160cc8ef2773d6755`). It verifies the complete archive inventory and original recording/ledger digests, then runs the new context and planner on those sealed original observations. This is not a current-job compatibility bypass: `--live-media` requires a current manifest-bound recording, and no old manifest is edited. Default sealed cases are compression, boundary, low-flag control and multilingual control. Use `--case` to select a bounded subset.
